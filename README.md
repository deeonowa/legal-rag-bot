# Legal RAG Bot — Юридический AI-ассистент

Локальная RAG-система (Retrieval-Augmented Generation) для работы с юридическими документами через Telegram-бота. 

## Возможности

- **Локальная работа** — все данные остаются на вашем компьютере
- **Telegram-бот** — удобный интерфейс для вопросов
- **Гибридный поиск** — BM25 + векторный поиск для максимальной точности
- **Поддержка PDF, TXT, MD** — загрузка документов разных форматов
- **Автоматическое кэширование** — быстрая работа после первой индексации
- **Источники ответов** — показывает, из каких документов взята информация
